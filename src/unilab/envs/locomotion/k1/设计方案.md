# K1SoccerDribble 设计方案

> 推进式与盘拉式分任务方案：`conf/offpolicy/task/flashsac/k1_soccer_dribble/带球方案.md`  
> 当前实现与平地走对比：`conf/offpolicy/task/flashsac/k1_soccer_dribble/任务分析.md`  
> 训练性能（sim 子步、benchmark）：`conf/offpolicy/task/flashsac/k1_soccer_dribble/训练性能分析.md`

## 目标

- 任务名：`K1SoccerDribble`
- 场景：仅 `K1 + 足球 + 地面`，不包含球场装饰资产。
- 训练算法：`flashsac`（motrix 后端）。
- 行为目标：机器人持续带球向前移动，减少把球踢飞或丢球。

## 场景设计

- 新增场景文件：`src/unilab/assets/robots/k1/scene_soccer_dribble_minimal.xml`
- 内容：
  - `include k1.xml`
  - `pitch` 视觉无限平面（`type=plane`、`contype=0`、`conaffinity=0`）
  - `COL_Collider` 无限碰撞地面（`type=plane`，`z=0`，摩擦与带球场景一致）
  - 足球资源来自 `sim_soccer2`（`Robot_Football.obj` + 贴图，见 `robots/k1/soccer_ball/`）
  - `ball_visual` 仅渲染；`ball_geom` 为同 mesh 的碰撞体（`mass=0.43`，加强滑动/滚动摩擦）
  - 球半径仍按 `0.09167862683534622`，初始高度为「平面 z=0 + 半径」
  - 为避免非物理连续弹跳，球体增加阻尼与更稳定接触参数（`damping/solref/solimp`）
  - `stand` keyframe 中同时初始化机器人与球位置

## 观测设计（速度命令 + 球观测）

单帧观测使用“命令 + 球 + 本体状态”：

- 保留速度命令特征（3 维，AMP 映射），且命令不再随机采样，改为“机器人指向球”的方向命令：
  - `cmd_vx`
  - `cmd_vy`
  - `cmd_wz`
- 额外加入球相关特征（3 维）：
  - `ball_rel_x_b`
  - `ball_rel_y_b`
  - `ball_rel_vx_b`
- 其余维度与 `K1WalkFlat` 一致：
  - 重力、陀螺仪、关节偏差、关节速度、上一步动作

因此推进式带球为单帧 **78** 维 actor、critic **81**（+3 局部线速度）；`obs_frame_stack=1`，不做历史堆叠。

## 奖励函数设计

总奖励仍采用 `run_reward_dispatch(scales * terms)` 形式，并在 `K1WalkFlat` 全量奖励基础上叠加带球项。

### 带球主奖励

- `ball_progress`：球在世界坐标 +X 方向的前进速度（鼓励推进）
- `ball_keep`：球与基座平面距离靠近目标距离 `ball_keep_distance`
- `ball_front`：球位于机器人前方且横向偏差小
- `ball_speed_match`：球前向速度与命令前向速度一致
- `ball_moving`：球平面速度达到最小目标 `ball_move_speed_target`（防止“机器人走了但球不动”）
- `ball_approach`：当球偏远时，奖励机器人对球的径向逼近速度（抑制“只绕不追”）
- `ball_still`：当球水平速度低于阈值 `ball_still_speed_threshold` 时给小惩罚

### 约束惩罚

- `ball_lost`：球平面距离超过 `ball_lost_distance` 后线性惩罚
- `ball_over_speed`：球水平速度超过 `ball_speed_cap`（当前 0.35 m/s）后惩罚（抑制爆踢）
- `ball_orbit`：惩罚围绕球的切向速度（抑制绕球转圈）
- `feet_inward_yaw`：只惩罚“脚朝另一只脚方向横过去”的髋 yaw 方向（左脚内横、右脚内横、双脚都朝内）
- 完整复用 `K1WalkFlat` 行走奖励：`tracking_lin_vel` / `tracking_ang_vel` / `forward_progress` /
  `under_speed` / `lin_vel_z` / `ang_vel_xy` / `base_height` / `orientation` / `action_rate` / `pose` /
  `feet_phase` / `feet_phase_contrast` / `feet_phase_contact` / `feet_double_stance` / `penalty_close_feet_xy`

### 终止条件

- 倾倒（倾角超过阈值）
- 基座高度低于阈值
- 球平面距离超过 `ball_lost_distance_hard`

## 训练配置

- 新增配置：`conf/offpolicy/task/flashsac/k1_soccer_dribble/motrix.yaml`
- 默认训练参数：
  - `num_envs=1024`
  - `max_iterations=20000`
  - `updates_per_step=2`
  - `batch_size=2048`
- 新增 warm-start 开关（当前默认关闭）：
  - `algo.warm_start.enabled=false`（当前默认从 0 开始训练）
  - 若手动打开，则默认从 `K1WalkFlat` 的 `flash_sac` 最新 run 加载 actor 参数
  - 可通过 `source_load_run/source_checkpoint` 指定具体模型

## 已知边界

- 当前目标方向固定为世界坐标 +X，不含复杂路径规划。
- 未引入球场边界与球门规则，仅优化“持续带球前行”。
